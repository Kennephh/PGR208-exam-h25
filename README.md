Eksamen i Android programmering, essensen i denne oppgaven var å hente animéer fra https://api.jikan.moe/v4/anime, vise en liste med animéer og kunne legge til i favoritter. Med en selvvalgt oppgave vi kom på var å opprette egne anime idéer.

Første eksamen der vi brukte Git og Github, vi lærte oss Git under eksamen og vi kjørte PR på alle commits. Slik at minst en annen i gruppa måtte godkjenne en commit før den ble merget inn til main. Vi jobbet også på egne branches for å unngå merge conflicts.
